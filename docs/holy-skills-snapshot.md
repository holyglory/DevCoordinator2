# Holy Skills Snapshot Provenance

The reusable agent assets in this repository were imported without Git ancestry
from the retired `holyskills` repository at commit
`d284b64464d2bbff0b6c8213fdb485a83d95bd80` on 2026-09-01.

The imported snapshot contains the five shared skills, canonical audit harness,
universal policy, issue ledgers, validation tooling, and locked browser-runtime
manifest. Repository-local scratch state, the obsolete governed-test adapter,
editor state, and prior merge-history prose were deliberately excluded.

The archived source repository retains its independent history for blame and
historical investigation. DevCoordinator2 is the only writable source after
the consolidation cutover, and installed skill entries link directly to it.
