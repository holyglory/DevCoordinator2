# Console typeface

InterVariable.woff2 is served locally; Console rendering makes no font requests
to third-party servers. The accompanying INTER-LICENSE.txt is the upstream SIL
Open Font License 1.1.

Source: https://rsms.me/inter/font-files/InterVariable.woff2

License source: https://github.com/rsms/inter/blob/master/LICENSE.txt

The system-font fallback remains available while the font loads. Authentication
and upstream-error documents remain self-contained and use the system fallback;
their static assets are not made public to load a typeface before sign-in.
