# DevCoordinator2

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The owner and authorized operators supervise multiple coding agents over tasks
lasting weeks. Administrators manage project ownership and explicitly approve
known data loss. Repository viewers inspect only the sources they may access.

## Product Purpose

Keep development work understandable, recoverable and accountable across agents,
Git repositories, local copies, deployments and build storage. The Console and
agent tools use the same Coordinator authority and execution records.

## Operating Context

A product project can own multiple Git repositories and physical copies. A
repository retains a primary editable checkout; concurrent feature work uses
temporary worktrees. Local deployments use immutable current and rollback
copies. Source and build storage occupy two declared project roots on separate
drives. Existing projects are migrated deliberately, one at a time.

## Project Explorer

The selected interface links a GitHub branch tree to local source/build copies,
with a detail editor below. Branches carry intent, outcome, owner, lifecycle and
links to Coordinator outcomes and GitHub pull requests. Commit ancestry can be
expanded. Storage figures distinguish measured, shared and unknown amounts.

Cached inventory appears before a fresh remote/local observation on every open.
Operators may edit metadata and remove proven-safe copies. Administrators approve
exact known data-loss plans and retire merged remote branches. Identity changes
invalidate prior removal approval. Primary edits and active deployments remain
protected.

## Completion

Feature changes are squash-merged, with exact original-head and resulting-commit
evidence. Completed local copies and feature refs are removed, including the
GitHub feature branch. Keep compact history and required evidence; do not create
whole-checkout archives. Removal is resumable and verified at its actual target.

## Visual Context

Use the existing Inter typography, dark/light semantic colors and bundled Tabler
icons. The authoritative explorer selection is Coordinator sketch
`s3ab8fce40b07f39e`, surface `console-project-explorer`; resolve its continuation
before implementation or audit. Mockup sample values are never product data.

## Accessibility and Reliability

Keyboard and touch users can inspect, select and edit the same objects. Status
has readable text as well as color. Large inventories are paginated; unavailable
credentials, observations and measurements remain visible rather than becoming
empty successful results.
