| UIL-DATA-USAGE-ANALYTICS-001 | Codex provider-token categorization and DevCoordinator2 repository usage charts | The agent proved an ideal fixture where a classified model operation owned the provider token row, then treated classified tool/model counts as evidence that real token totals would also be categorized; in live multi-agent work the token-bearing delegated or next-turn operations remained `unknown` while classified operations carried no token rows | Keep `unknown` visible whenever the canonical token-bearing operation is unclassified, never move tokens to a nearby activity by guesswork, and do not claim activity categorization works until declarations survive the actual delegated-thread and turn boundaries that emit provider usage | Test same-turn, next-turn, parent/delegated-thread, tokenless-classified-operation, and token-bearing-unknown-operation cases in the canonical collector and the downstream aggregate; prove provider `total_tokens` remains invariant, classified shares come only from the owning operation, partial coverage remains explicit, and a real repository report no longer collapses to 100% unknown when declarations were made |
